# AstraPlusCar HarmonyOS 手机控制端

[English](README.md) | 简体中文


本应用的目标版本与最低兼容版本均为 HarmonyOS API 23。手机、小车、电脑接入同一个 WLAN 后，在连接页填写小车 HTTP 地址；2026-09-30 实车联调地址和当前默认值为 `http://192.168.8.204:8080`。地址变化时以小车实际 IP 为准。接口及部署方式见 [Phone API](../AstraPlusCar-device/docs/PHONE_API.md)。

## 界面与控制

连接状态采用居中小车与左右分支布局：左侧为视频、雷达，右侧为语音、模型，四个模块分别通过连接线接到小车，表示它们依赖车辆连接。视频与雷达只有在小车连接且对应模块就绪时显示在线；语音在语音模式识别启动成功时显示在线，模型暂固定显示离线。主页和连接页复用同一组件，状态区域保持紧凑。此前连接状态布局已通过 HAP 构建，并在鸿蒙手机上复核主页、连接页的四条连线与文字显示；验证时小车未连接，未发送运动指令。

视频默认使用有界短段 MJPEG，目标 30 FPS：请求 `/api/v1/camera/stream.mjpg?fps=30&frames=12`，每段正常传完 12 帧后关闭，每 300 ms 提前开启下一段，最多三个请求在途。单段最长保留 900 ms，忽略开始超过 750 ms 后到达的数据，并以各段的 `X-Frame-Sequence` 丢弃重复/倒退源帧。单个连接重传时，后续短段可独立送帧；正常播放保留连续收包，避免高频单图 HTTP 的开销。车端仍支持持续 MJPEG 与单帧接口。相机按 720p / 30 FPS 采集，驾驶预览为 640×360，截图保持 720p；界面显示实际解码 FPS，重复源帧不会刷新看门狗。连接预览时保持窗口亮屏，连接前固定局域网路由并禁用 HTTP 代理。超过 2 秒无新画面会断开控制并发停车；已有画面的连接在前台等待 0.5 秒自动重连一次，连接或恢复失败则提示手动连接。收到新画面前禁止运动和调速，不恢复旧会话、按键或运动。主动断开、取消连接或退后台会取消重连，车端 600 ms 看门狗继续生效。状态轮询不重叠，旧连接的迟到响应不能覆盖新连接；车端重启后重新建连。

竖屏主页依次显示连接状态、16:9 视频、控制盘和底部“停车 · 急停”按钮。横竖屏主页及连接页的视频统一叠加雷达环，移除原来视频下方的独立雷达条；窄画面会调整环的纵向位置并将左右距离标签保持在视频边界内。仅对有效距离 ≤0.50 m 的方向显示环和米制距离（例如 API 的 100 mm 显示为 0.10 m），红色 ≤0.20 m、黄色 0.20–0.50 m。任意方向进入橙色警戒区（0.20–0.50 m）时给予一次轻振，进入红色危险区（≤0.20 m）时给予一次更强振动；雷达反馈由独立的 RadarHaptics 定义，橙色为 soft 预设、单次、强度 20，红色为 hard 预设、单次、强度 65；普通按钮的轻振和强振分别使用 soft / hard 预设、单次、强度均为 50。共用的预设执行器会缓存硬件与效果支持情况并记录启动错误。同色距离更新不重复振动，同时进入多个警戒区时合并为一次振动并优先红色。较远、没有回波、雷达不可用或数据过期时隐藏环；雷达连接状态仍由连接状态组件显示，不将无读数解释为安全距离，也不对正数读数设置 100 mm 的下限。距离来自雷达安装零位下的 270°、0°、90° 方向各 ±30° 范围内最近回波，按雷达中心计算，需要确保零位朝向车头。近距离无回波可能涉及雷达盲区，不能仅靠 App 换算解决，需结合实车距离与原始读数核对。

连接页显式顶部对齐，重新打开时回到顶部。最上方为带“车端地址”标签和 Wi-Fi / IP / 端口说明的连接框，下方依次为连接状态、视频与雷达。页面保留前、左、右三向原始毫米读数、最近扫描的数据龄、颜色阈值与测量说明，便于现场校验。手机每 250 ms 轮询状态，同一连接内不重叠请求；当前车端约每秒发布一个最近回波窗口，App 更快轮询减少取到新窗口的等待，不能提高硬件或车端的发布频率。数据龄直接使用车端的单调时钟年龄，避免车端日历时间不准确影响显示。

控制盘中间为“截图”，触摸视频也可截图；屏幕最底部保留独立的“停车 · 急停”。四个主要方向是前进、左转、后退、右转，四角是左右旋转与左右平移。右侧按钮文字位于对应触摸区域内。按住运动区时仅允许一个动作生效，第二个手指不能同时触发另一方向；滑到新方向时先停车再切换，松手或触摸取消即停车。速度滑块在运动按住期间同样可用：拖动时约每 120 ms 提交最新速度，沿用当前运动会话与续期 ID，不必松开方向。松手、急停或换方向后的迟到调速响应不会更新新动作。断联、App 退后台和画面方向切换时释放当前动作；车端还有 600 ms 控制续期看门狗。

横屏隐藏 HdsNavigation 标题栏（标题位置留空），内容区因此等于整个窗口，不再有标题栏高度在底部留下的空带；“语音 / 连接 / 图库”位于画面右上角的三个圆形叠加按钮，横屏仍可打开连接页和图库，图库页保留自己的标题栏与返回按钮。16:9 视频保持原始比例居中显示（`ImageFit.Contain`）：屏幕比 16:9 更宽时左右黑边对称，更高时上下黑边对称，不再出现只有一侧的黑边或裁切画面。摇杆、速度滑块与雷达色带叠在画面上，用单条 12 vp 宽的椭圆色带显示前、右、左三向迫近提示，不绘制后方，也不按危险程度增加条数。只有有效距离 ≤0.50 m 的方向才显示色带和距离，较远、无回波或雷达不可用时隐藏。黄色与红色区分警戒程度；不透明度随距离缩短从 20% 连续提高，最高 50%，色带两端渐变至透明。颜色与深浅变化使用 320 ms 平滑动画，出现和消退使用 280 ms 淡入淡出。环内部透明，整层不拦截控制触摸。竖屏和连接页的视频复用相同雷达环，连接页仍保留三向原始毫米读数和扫描数据龄。横屏左侧摇杆控制前进、后退、左右转弯，中央是停车；右侧摇杆左/右为左旋转/右旋转，上/下为左平移/右平移，中央是截图；速度滑块位于画面左上角，容器高 32 vp，底色不透明度约 25%，其下显示实际解码 FPS。横屏方向按钮的空闲底色不透明度约 33%、按下约 53%，停车和截图底色约 60% 和 53%；文字保持清晰。画面底部指令框按文字自然宽度加内边距居中显示，最长限制在两侧控制盘之间，超长文字省略，减少对中央视野的遮挡。两套摇杆同样互斥。摇杆文字位置与宽度在构建时按当前摇杆直径计算（只把固定比例传给 `@Builder`，直径在构建器内部读取），随尺寸变化刷新，不再停留在首次布局的旧尺寸上。需要人工停车时可使用左侧中央按钮。连接页在横屏可滚动。

截图先保存在车端，再下载到应用私有图库，重启后仍可查看。用户主动选择“下载”并完成系统授权后，图片才进入系统相册。车端没有日志流接口，因此应用不提供控制台页面。

## 构建与联调

2026-10-05 新增语音控制：竖屏标题栏和横屏右上角均提供麦克风按钮，点击进入语音模式，再点一次或侧滑返回退出。小车连接且实时画面就绪后可开启；首次使用请求麦克风权限。使用 Core Speech Kit 离线中文识别（`online: 1`、`recognitionMode: 0`），由系统采集麦克风，显示中间识别文本，只执行最终确认的完整指令。语音模式通过 UI Design Kit 原生双边边缘流光提示；横屏隐藏双摇杆与手动速度滑块，显示语音识别/执行卡片及独立截图、停车按钮，短屏幕下卡片可滚动；竖屏将控制盘替换为格式化语音卡片，保留截图与底部停车入口。

支持前进、后退、左转、右转、左右旋转、左右平移、停车/急停、截图/拍照、加速、减速、设置速度（如“速度五十”）和退出语音。本地语法支持常用同义表达：直行、前行、往前走都映射为前进，倒车映射为后退，左拐/右拐映射为转弯。支持组合指令，例如“速度100前进三秒再右转”理解为“速度 100 → 前进 3 秒 → 右转 2 秒”，先完整验证整句话，再按顺序执行；调速、运动开始和动作间停车均需收到确认，计划任一步失败会取消后续步骤。识别将一句话拆成多段时，以“然后/接着/再”开头的后续子句会追加到当前计划；新的独立方向指令替换原计划，停车立即取消整组。每组最多 8 步、运动总时长最多 30 秒；无法理解或不完整的组合整组不执行。语音卡片显示识别原文、理解后的步骤和执行进度。

运动默认持续 2 秒，也可说“前进三秒”或“直行半秒”，单个动作时长范围 0.5–10 秒，到时自动发停车；语音运动复用现有控制会话和 150 ms 续期，保留车端 600 ms 看门狗。进入/退出语音、语音停车和成功执行运动/调速/截图均提供振动。急停会取消当前识别子句，避免迟到的最终识别重新启动运动；退出、打开连接或图库、断联和退后台释放识别与运动并取消整个计划。切换横竖屏时停止当前动作并丢弃待执行识别，语音模式保留，用户需重新下达指令。权限拒绝、启动超时及识别错误会退出语音模式并发停车；连接恢复不会自动重进语音或恢复旧动作。

语音回归：`node tools/check-voice-control.cjs` 使用真实 ArkTS 方法和模拟识别/网络回调，覆盖同义表达、完整组合解析、中文数字和小数时长、否定/不完整组合拒绝、顺序执行与停车确认等待、分段识别追加、计划限额、任一步失败取消、权限/引擎迟到取消、识别去重与会话轮换、动作时限、调速期间到时停车、急停/返回/旋转/断联/后台后迟到指令隔离、振动及失败反馈。该功能已通过 HAP 构建和离线检查，尚未完成真机语音识别、流光显示、振动感受及实车运动验证。依据：[双边边缘流光](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/ui-design-visual-effect-double-edge-streamer)、[语音识别 API](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/hms-ai-speechrecognizer)。
