# AstraPlusCar HarmonyOS 手机控制端

本应用的目标版本与最低兼容版本均为 HarmonyOS API 23。手机、小车、电脑接入同一个 WLAN 后，在连接页填写小车 HTTP 地址；2026-09-30 实车联调地址和当前默认值为 `http://192.168.8.204:8080`。地址变化时以小车实际 IP 为准。接口及部署方式见 [Phone API](../AstraPlusCar-device/docs/PHONE_API.md)。

## 界面与控制

竖屏主页依次显示连接状态、16:9 视频、视频下方独立雷达条、控制盘和底部“停车 · 急停”按钮。雷达按“左、前、右”排列，显示当前扇区最近距离的纯数值，单位实际为毫米；距离不超过 300 mm 显示红色，301–800 mm 显示橙色，更远显示绿色，暂无有效数据显示 `--`。三个扇区分别取车端 270°、0°、90° 方向 ±30° 范围，后方不在界面展示。雷达数值来自完整旋转扫描，不是只读取前方。连接页也将同样的三向雷达条放在视频预览下方。

控制盘中间为“截图”，触摸视频也可截图；屏幕最底部保留独立的“停车 · 急停”。四个主要方向是前进、左转、后退、右转，四角是左右旋转与左右平移。右侧按钮文字位于对应触摸区域内。按住运动区时仅允许一个动作生效，第二个手指不能同时触发另一方向；滑到新方向时先停车再切换，松手或触摸取消即停车。速度滑块在运动按住期间不发新的速度命令。断联、App 退后台和画面方向切换时释放当前动作；车端还有 600 ms 控制续期看门狗。

横屏保持 16:9 视频尽量铺满可用区域，雷达条以半透明底色叠在画面上方，不因雷达缩小视频。横屏左侧摇杆中央是停车，右侧摇杆中央是截图；顶部保留车辆状态、速度滑块和相册入口。两套摇杆同样互斥。需要人工停车时可使用左侧中央按钮。连接页在横屏可滚动。

截图先保存在车端，再下载到应用私有图库，重启后仍可查看。用户主动选择“下载”并完成系统授权后，图片才进入系统相册。车端没有日志流接口，因此应用不提供控制台页面。

## 构建与联调

在本仓库执行：

```bash
/Users/raychen/Applications/DevEco-Studio.app/Contents/tools/hvigor/bin/hvigorw \
  assembleHap --mode module -p product=default -p module=entry@default \
  -p buildMode=debug --no-daemon
```

调试包位于 `entry/build/default/outputs/default/entry-default-signed.hap`。2026-09-30 已在真机安装构建包，并在同 WLAN 下连到真实小车，确认视频、三向雷达、截图与手机私有图库；API 侧确认了状态、MJPEG、截图下载、速度、全部方向命令、续期、停车、旧会话拒绝和 600 ms 失联自动停车。车轮悬空时仅做短时运动命令；实际轮向、落地行驶和 App 后台停车还需现场观察。车端此次运行在独立联调目录，临时 `astra-phone-integration.service` 在 SSH 退出后仍在线，但不会在重启后自动恢复；正式的 `astra-phone.service` 尚未安装。详细状态和服务部署说明见设备端 README 与 Phone API。
